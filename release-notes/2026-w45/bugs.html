Bug fixes15

School dashboard5

  • Extend no longer always says the quote failedLive

    When a school clicked Extend, all holidays were ticked by default and the quote always failed. The list now shows only holidays that overlap the extension window, and the quote works.

    2026-11-04velo#2055 pages#1870
  • Pupils table: Start month written the same way as EndLive

    Start months before September were shown inconsistently. Start now uses short forms like Sep, the same as End.

    2026-11-02pages#1834
  • Phone: school pupil list no longer cut off on the rightLive

    On a 320px-wide phone, the expiry marker pushed each row on the school home list off the edge. The marker now sits on its own line.

    2026-11-03pages#1848
  • Groups table: ⋯ menu no longer hidden with one rowLive

    The menu was clipped by the table container and could not be clicked. It now opens according to its position on screen.

    2026-11-03pages#1852
  • Lesson report: pupil ID no longer blankLive

    The pupil ID in the school home lesson report was empty (QE found 200 of 200 blank). It is now filled in.

    2026-11-04velo#2063

Trust / LA dashboard4

  • Trusts with no member schools: no false amber bannerLive

    For a trust with no member schools, the dashboard always showed an amber 'unavailable' banner, and the timeout message was inaccurate. The wording now matches what is actually happening.

    2026-11-05velo#2099 velo#2100

    Confirming the timetable on a self-created card used to fail for these trusts. It now works.

    2026-11-06velo#2139

    The dropdown no longer accepts an empty school ID (fixed in passing during the module split).

    2026-11-05pages#1897
