School dashboard9

  • Account card and billing blocks now actually appearLive

    The payer account card was hidden for every school because the page expected a nested data layer the live snapshot does not have. The page now reads both shapes. Several back-end reads of the account card were also tightened (unavailable states named, system keys ignored).

    Order rows with a missing days-left value show “not fully loaded”, the start-date box resets to the minimum end date, an end date earlier than the allowed minimum no longer sends a quote, and the Groups page says B / D are groups while one-to-one products live on Pupils.

    2026-11-16pages#2054 pages#2056 pages#2062 pages#2068
  • Pupil-type Extend: exact prices backLive

    Academy, Compass and Evolve extension quotes returned no exact price; they are exact again, a single sub-category is picked automatically, and the follow-on order carries the original order number so finance and the confirmation letter recognise it as a renewal.

    2026-11-19velo#2490 velo#2494 velo#2506

    Re-working the end date of an order, including a weekly-paid student order, no longer always concludes “units unknown”.

    2026-11-22velo#2576 velo#2585

    At 640px and narrower the action buttons wrap below the text, so a 320px screen no longer scrolls sideways.

    2026-11-22pages#2189

    Attendance tables with several pupils now show high attendance in green; amber and red are unchanged.

    2026-11-16pages#2069

    A reply that arrives after the pop-up was closed or replaced is ignored instead of being written into it.
