  • Daily billing run (NO.8107 / 8118): split into segments with their own jobs and time budgets, a third segment for commission, pending items and the account tail (velo#2554, #2581, #2595), a second Lark segment (velo#2535), a school-by-school batch mode that runs in shadow only (velo#2569, #2590), heartbeats and memory logs to find where it stalls (velo#2512, #2566, #2586), and an internal run-now entry (velo#2532, #2582).

  • Parent identity in one place: three copies of “find the parent by user ID” merged into one execution point, with a baseline test and a never-throw trace layer (velo#2442, #2445, #2455, #2420, #2424, #2434, #2458).
  • uiVersion sync made automatic: light-weight check for one-line syncs, auto-opened sync PRs and a double read before publish (velo#2431, #2439, #2446); 10 PRs this week carry uiVersion in the title.
  • Retired pages and methods: the old /spv2 student page, /st-add-student, the extend trail pilot page and dead enrolment code removed; a retired-method scan added to CI in both repos (velo#2370, #2411, #2413, #2545, #2519, #2371, pages#2169).
  • Publish size budget (NO.8037): a total-size check in pre-publish, the mirror page limit raised to 1.5M with oversize pages skipped one by one, comment stripping on the school-home bundle, and on-demand fonts for the enrolment page (velo#2561, #2570, #2557, pages#2201, #2206, #2230).
  • CI: lighter runners for CI checks (velo#2432, #2448, #2437, pages#2233, #2237), pages viewport matrix grown from 14 to 18 shards (pages#2146, #2194) and a rule that rebuilds shard baselines after a spec is split (pages#2207), stale-round exits (velo#2453, pages#2095, #2213).
  • Tests made faster and steadier: 36 pages test PRs this week, mostly replacing fixed real-time waits with a frozen clock or real signals, plus a repo-wide ratchet that blocks new long waits (pages#2113, #2168, #2228).
  • Specs and docs: 72 spec / docs PRs, plus 16 automatic Velo mirror refreshes.
