Bug fixes22

School dashboard12

  • Large schools' home page no longer times outLive

    The home page of a school with very many records could hit a 60-second timeout. Slow sections now give way, the first screen no longer reads report data it does not show, and pupil, feedback and ticket sections load lighter data first.

    2026-11-11velo#2282 velo#2284 velo#2289 velo#2291 velo#2293 pages#2011
  • Remove pupil: deactivated pupils no longer flagged as unmatchedLive

    A roster entry that matches a deactivated pupil is no longer counted as not matching, and no warning is shown. The list is read for the whole school and compared case-insensitively.

    2026-11-15velo#2361 velo#2364 velo#2367
  • Groups table: first name no longer croppedLive

    In the ENROLLED list and the ⋯ menu, the first name was cut off at the top. The menu now opens according to the button's position.

    2026-11-11pages#2009
  • Phone: calendar toolbar fits 287px and Previous points leftLive

    On a very narrow phone the calendar toolbar cut off its text, and the Previous arrow pointed the wrong way.

    2026-11-15pages#2051
  • Internal tickets no longer visible to schoolsLive

    Tickets marked internal, or raised by the Call Centre or an internal source, no longer appear in the school's ticket list, recent tickets or Open tickets card.

    2026-11-13velo#2295 velo#2315
  • Open tickets card counts what the ticket page countsLive

    The card counts only Open and In Progress tickets and leaves out internal ones. Users who see only their own pupils get a count for those pupils.

    2026-11-12velo#2306 velo#2320
  • Limited-role users can find tickets they raisedLive

    For users whose access is limited to their own pupils, the tickets they raised themselves could not be recognised. Tickets from school and trust dashboards now record the signed-in person's login email, so this works.

    2026-11-14velo#2326 velo#2331 velo#2337
  • PO number saved: dashboard updates straight awayLive

    After saving a PO number, the order no longer slips back to Awaiting PO when you switch tabs, and the Overview count drops. Fixed for schools and trusts.

    2026-11-13pages#2025 pages#2026
  • Overview attendance counts only current pupilsLive

    The two attendance figures on Overview now count only pupils currently on the roll.

    2026-11-13velo#2335
  • Groups: Group Add requests In Progress count as in flightLive

    Capacity checks and duplicate checks for re-enrolling a pupil now treat an In Progress Group Add request as already under way. Same rule for trusts.

    2026-11-09velo#2224 velo#2227
  • Extend: no more half-failed orders when learning-from-home is missingLive

    If the original order has no learning-from-home value, Extend is refused before an order is placed and points to Contact us. A related fix passes the value on correctly for pupil-type orders.

    2026-11-14velo#2336 velo#2344
  • Extend on B / D courses: errors fixedLive since 16 Nov (batch 208)

    Extending a B or D course goes by order, not by class number, so the error schools and trusts hit on B/D courses goes away. The back end went live during the week; the page change shipped with batch 208 on 16 Nov and is being checked on the live site.

    2026-11-15velo#2342 velo#2349 pages#2052 velo#2375

Ops & internal tools5

  • Daily billing run: slow steps time out instead of blocking the restLive

    Two to-do steps and the finance-table steps are now limited to 60 seconds each and the whole daily run to 180 seconds, so commission and other later steps are not held up.

    2026-11-15velo#2322 velo#2357 velo#2362
  • Billing flag: overbilled only when invoiced is above order totalLive

    The over-billed flag is raised only when the amount invoiced is more than the order total.

    2026-11-12velo#2302
  • Internal lesson reads no longer show 0 when unknownLive

    If a page of lessons cannot be read or a count cannot be worked out, the internal lesson read now says so instead of showing 0.

    2026-11-13velo#2324
  • Call Centre: test pupils are not scheduledLive

    Pupils with UAT-style test emails are no longer put in the call list.

    2026-11-12velo#2308
  • Assign pupils: a slow read is retried onceLive since 16 Nov (batch 208)

    When saving an assignment, a slow read is retried once and the whole save has one time limit.
